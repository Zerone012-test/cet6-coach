# CET-6 翻译与写作智能教练 Skill

> 适用于 Claude.ai 的大学英语六级备考助手，支持作文评分、翻译评分、错误诊断、表达升级和中英表达查询。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 📝 作文评分 | 模拟六级评分标准，输出内容/语言/结构三维评分 |
| 🔤 翻译评分 | 按准确性/流畅性/完整性评分，结合真题参考译文 |
| 🔍 错误诊断 | 自动识别语法、词汇、搭配、中式英语等6类错误 |
| ⬆️ 表达升级 | 识别低分表达，推荐六级高分替换方案 |
| 🔎 中英表达查询 | 查询某个中文表达的英文说法，附真题例句 |
| 🔄 英文反向查询 | 查询某个英文表达的含义、用法和真题来源 |

---

## 安装方法

### 方法一：下载 .skill 文件安装（推荐）

1. 在本页面的 Releases 中下载最新的 `cet6-coach.skill` 文件
2. 打开 [Claude.ai](https://claude.ai)
3. 进入 **设置 → Skills**，点击 **安装 Skill**
4. 上传下载的 `.skill` 文件即可

### 方法二：手动安装

将本仓库克隆到本地，在 Claude 设置中指向 `cet6-coach/` 文件夹。

## 知识库说明

本 Skill 内置三个知识库文件：

### 📚 翻译表达知识库（`references/cet6_phrases.json`）
- **71 条**高频翻译表达
- **5 大分类**：核心翻译表达、高频政策表达、科技表达、传统文化表达、可持续发展表达
- **11 个主题**：经济、文化、科技、教育、环境、社会等
- 含 2023-2025 年真题例句

### 📝 历年写作真题（`references/past_essays.json`）
- 覆盖 **2023年6月 ~ 2025年12月**，共 **18 套**真题
- 每套含：题目首句（英/中）、主题标签、核心短语
- 支持按年份、主题检索

### 📊 官方评分标准（`references/scoring_criteria.md`）
- 来源：《全国大学英语四、六级考试大纲（2016年修订版）》
- 包含作文和翻译的**五档评分标准**（原文）

## 使用示例

**作文评分**：
> 直接粘贴你的作文，Claude 会输出评分报告 + 错误诊断 + 表达升级建议

**表达查询**：
> "走向全球市场 英语怎么说" → 输出多个英文表达 + 真题例句 + 迁移用法

**翻译评分**：
> 粘贴你的翻译段落，Claude 会对比参考译文并给出评分
